## Leyenda

| Estado | Significado |
|---|---|
| Cerrado | Tenemos precio y duración suficiente para web/agenda. |
| Por confirmar | Existe en catálogo, pero falta duración exacta o matiz operativo. |
| Estimado / confirmar | Hay una duración probable por familia de servicio, pero conviene validarla con la clienta. |
| No aplica | Ese servicio no aparece para ese mercado. |

## Estado de tiempos

Todas las duraciones de cita del catálogo quedan cerradas para web/agenda. Algunos servicios tienen rango porque dependen del diseño, decoración o estado inicial.

---

## Nota para la web

- Para servicios con duración cerrada, se puede mostrar el tiempo directamente.
- Para servicios con rango, conviene mostrar “desde”, “aprox.” o “según diseño/decorado”.
- Ya no quedan servicios del catálogo sin duración de cita.
- Para Suiza: no mostrar HidraLips ni depilaciones. Refuerzo de cejas híbridas confirmado a 150 CHF.
