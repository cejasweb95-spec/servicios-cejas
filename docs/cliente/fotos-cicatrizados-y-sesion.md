# Cicatrizados + Sesión Profesional — Inventario

Lote de 22 fotos. La cliente lo introdujo como "Cicatrizados", pero contiene **dos bloques distintos**.

---

## 1. Cicatrizados (8) — `assets-extraidos/cicatrizados/`

Resultados de micropigmentación **ya curados** (cómo queda el trabajo tras la cicatrización completa, no recién hecho). Incluye cejas y labios, mayormente capturas de Instagram Stories.

- **Valor para la web:** muy importante para mostrar resultados reales y duraderos → sección de galería "Resultados cicatrizados" o comparativas antes/después.
- Algunas son capturas de stories (con UI del móvil) → recortar para uso en web.

---

## 2. Sesión de fotos profesional de Xiomara (14) — `assets-extraidos/xiomara-sesion-profesional/`

**Material de marca de alta calidad.** Sesión de estudio profesional con fondo palo de rosa (¡coherente con la paleta de marca!). Looks:

- Retratos con **uniforme negro** (elegante, profesional).
- Retratos con **traje blanco** (sofisticado).
- Retratos con **uniforme azul** de trabajo.
- Retratos con **uniforme verde/caqui sosteniendo un globo terráqueo** → 🌍 **concepto "internacional" perfecto** para la identidad de "Cejas Internacionales".
- Fotos dentro de la **cabina del estudio** (camillas, aros de luz, pared de certificados, paredes palo de rosa).

### Usos sugeridos en la web
| Foto | Uso |
|---|---|
| Globo terráqueo (verde) | Hero / sección "internacional" / bloque de marca |
| Traje blanco / negro | "Sobre mí", cabecera, bloque de confianza |
| Uniforme azul en cabina | "Sobre mí", sección de proceso/profesionalidad |
| Cabina del estudio | Bloque de confianza / contacto / "el estudio" |

> Estas son, con diferencia, las **mejores fotos de marca** que tenemos. Base ideal para hero y "Sobre mí".
